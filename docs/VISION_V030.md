# Hertz v0.30 战略方向——从「内容工厂」到「创作者工坊」

> 状态：已交付（v0.30.0）· 规划 2026-08-24 / 收口 2026-09-23  
> 前提：v0.22 已交付完整流水线基建（采集→闸门→制作→审核→发布）  
> 本文档回答三个问题：为什么转、转成什么、怎么到那里。

---

## 一、为什么必须转向

三条不可逆趋势交汇，构成转向的根本动机。

### 1.1 AI 内容泛滥 → 观众反噬

批量生成的模板化内容正在被平台降权、被观众跳过。「AI 味」成为贬义词：
模板化叙事、无个性旁白、批量感封面。当所有人都能用 AI 生成内容时，
稀缺的不再是产能，而是**有人的温度的内容**。

### 1.2 API 成本不可持续

当前每条视频消耗 6-8 次 LLM 调用（评分/脚本/翻译/包装）。按日产 5 条
计算，月耗 1000+ 次。API 定价趋势是持续上涨直至企业级区间，个人创作者
的边际成本将超过收益。依赖远端 API 的自动化在成本拐点后将不可运转。

### 1.3 全自动 ≠ 有价值

Hertz 的流水线已证明「能自动跑通」。但跑通 ≠ 有人看。产量不是护城河——
**观众的注意力才是稀缺资源**。系统应当放大人的创造力而非替代它。

### 结论

Hertz 需要从「用 AI 替代人」转变为「用系统放大人」。
工作流编排、发布策略引擎、栏目化管理是真正的护城河——它们与底层
智能引擎解耦，在任何供给模式下都成立。

## 三、新能力抽象层

以下四个能力构成 v0.30 的功能骨架。每项遵循同一设计公理：

> **工具优化机械环节（时间轴对齐/格式转换/排期计算），创意决策 100% 归人。
> 工具在人创作时隐形，在做重复劳动时显形。**

### 能力一：脚本工坊（Script Atelier）

让每个字都出自人之手，但让写作过程比打字快三倍。

- **语音草稿**：对麦克风说 3 分钟想法 → faster-whisper 本地转写 → 可编辑文本。
  比打字快且保留口语自然感（无 AI 味的根源：是你自己的话）。
- **逐句打磨模式**：每句一行显示，拖拽排序调整叙事顺序，标记重读词，
  实时预估朗读时长并提示是否超预算。
- **风格锚点**：保存自己最满意的段落作为风格参照。后续写作时对照检查——
  不是让 AI 模仿你，是你自己保持声音一致。
- 与现有链路的关系：产出的脚本直接进入既有 TTS → ASS 字幕 → ffmpeg
  合成管线。上游变了，下游零改动。

### 能力二：创作资产图（Creative Asset Graph）

素材不只是文件存储——它是可组合的创作积木，片段之间有语义关联。

- **灵感片段标记**：浏览任何视频时标记「这个转场不错」→ 存为可检索的
  技法参考（与原始素材分离——你收藏的是手法，不是文件本身）。
- **素材组合预览**：选几个片段拖拽排序 → 不开剪辑软件即可验证拼接节奏。
  降低「从灵感到可用素材」之间的摩擦。
- **灵感笔记 ↔ 素材关联**：一条笔记可以链接多个素材文件。做专题时
  一键调出所有相关素材，不用回忆存在哪里。
- **视觉风格预设**：字体/颜色/片头片尾/转场方式 定义一次全局生效。
  观众看到第 3 秒就知道是你的视频。

### 能力三：智能降级路由（Intelligence Router）

同一个任务接口，多种供给实现，按内容价值自动选档。

```
供给层级：
Tier A  远端 API      重要内容，高质量要求（三步法翻译等）
Tier B  本地小模型    常规内容，够用即可（Ollama / Opus-MT）
Tier C  规则+模板     机械性任务，零成本（启发式评分/标题模板）
Tier D  人工输入      创意决策点（脚本工坊产出）
```

路由依据 = 月度预算阶梯状态 × 内容重要性 × 历史质量反馈。
复用 TaskRouter 已有的角色解析和 model_key 覆盖机制；
新增成本感知降级逻辑（<50% 正常 / 50-80% 自动降级 /
80-95% 强制本地 / >95% 仅人工触发）。

### 能力四：半自动运营面板（Operations Console）

人拍板，系统执行——交接丝滑。

- **批量制作队列**：拖拽排序优先级，一键套用栏目参数
- **键盘快捷键全覆盖**：j/k/a/r/Enter 不碰鼠标走完全流程
- **内容日历增强**：周视图拖拽 + 栏目色彩标记 + 发布窗口热力图
- **制作结果摘要**：warnings/errors 在审核卡直接可见（含预检警告徽章）

## 四、技术架构演进原则

| 原则 | 含义 |
|---|---|
| 接口不变，实现可换 | TaskRouter 的 score/script/synthesize 接口签名不动；底层从远端 API 切到 Ollama 到规则引擎到人工，上层无感知 |
| 降级显性化 | 任何自动降级必须在 UI 有对应标识（⚠️ 徽章/颜色/文案），不允许静默 |
| 人是最高优先级 Provider | 系统中所有「待人工决策」的队列项与 AI 任务同优先级调度 |
| 本地优先 | 新功能默认离线可用；联网能力作为可选增强 |
| 单向依赖 | infra ← common ← domain ← orchestration；禁止反向 |

## 五、非目标

- ❌ 不做全自动无人值守内容农场
- ❌ 不做通用视频剪辑器（CapCut/Premiere 已经够好）
- ❌ 不做多平台社媒管理 SaaS
- ❌ 不追求日产量指标
- ❌ 不做通用 AI 写作助手（定位是辅助创作者保持自我声音，不是替人写作）
