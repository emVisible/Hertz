# Hertz API 清单（Phase 4.1 地基回哺：monoline CONFIG 双向比对思想）

本文件由 `tests/test_api_surface.py` 与运行中的应用双向比对：
- 文档里有、应用里没有 → ghost（删了接口没更新文档）；
- 应用里没有、文档里有 → missing（加了接口没登记）。
任一方向不一致测试即失败。新增/删除接口后执行
`uv run python scripts/api_inventory.py` 同步本表。
